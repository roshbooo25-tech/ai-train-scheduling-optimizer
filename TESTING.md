
# Test Cases

1. Open index.html: dashboard loads without a server or API key.
2. Navigate through all five sidebar pages.
3. Search for TR101: matching train appears.
4. Search for a nonexistent ID: no matching rows appear.
5. Add a unique train ID: the new record appears.
6. Add a duplicate ID: an error message is shown.
7. Change a train status: table and KPI cards update.
8. Click Optimize Schedule: a simulated recommendation appears.
9. Mark a delay alert reviewed: its status changes.
10. Resize to a mobile viewport: navigation and tables remain usable.

These are manual test cases. They must be executed in the target browser before reporting them as passed.
